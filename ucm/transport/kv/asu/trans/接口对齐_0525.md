## CreateConnection

```C++
Input:
  localIp: 本端 IP 地址
  remoteIp: 对端 IP 地址
  port: 建链使用的端口
  qpNum: 需要创建的连接 / QP 数量
  timeout: 建链超时时间
Output:
  connectionHandles: 创建成功后的连接句柄列表，成功时 size == qpNum
Return:
  Status: 建链整体结果
    SUCCESS 表示建链成功
    非 SUCCESS 表示建链失败

using ConnectionHandle = uint64_t;

Status CreateConnection(
const std::string &localIp, 
const std::string &remoteIp, 
uint32_t port, 
uint32_t qpNum,
uint32_t timeout, 
std::vector<ConnectionHandle> &connectionHandles);
```

## DeleteConnections

```C++
Input:
  connectionHandles: N 个待断链并释放资源的连接句柄

Output:
  std::vector<Status>: 每个连接的断链和资源释放结果
    statuses[i] 对应 connectionHandles[i]
    SUCCESS 表示该连接处理成功
    非 SUCCESS 表示该连接处理失败
    
using ConnectionHandle = uint64_t;
std::vector<Status> DeleteConnections(const std::vector<ConnectionHandle> &connectionHandles);
```

## Send

```C++
Input:
  ioBatches: N 个待发送 IO 描述
    connectionHandle: 连接句柄
    sendBuffer: 待发送 buffer 的起始指针
    flagBuffer: flag buffer 的起始指针
  AIV专用：
  kernelCount: AIV 执行使用的 block 数量
  quietCount: 每发送 quietCount 次 IO 后执行一次 PollCQ

Output:
  std::vector<Status>: 每个 send 的执行结果
    statuses[i] 对应 ioBatches[i]
    SUCCESS 表示该 send 成功
    非 SUCCESS 表示该 send 失败

struct SendIoBatch {
  ConnectionHandle connectionHandle;
  void *sendBuffer;
  void *flagBuffer;
};

std::vector<Status> Send(const std::vector<SendIoBatch> &ioBatches, uint32_t kernelCount, uint32_t quietCount);
```

## RegisterMemory

```C++
Input:
  connectionHandle: 连接句柄
  memoryDescs: N 段待注册内存
    memoryType: MEM_DEVICE / MEM_HOST
    addr: 内存地址
    size: 内存大小

Output:
  memoryHandles: 每段内存对应的注册句柄，size == memoryDescs.size()
  return Status: 整体注册结果   

enum MemType {
  MEM_DEVICE,
  MEM_HOST
};

struct RegisterMemoryDesc {
  MemType memoryType;
  uintptr_t addr;
  size_t size;
};

Status RegisterMemory(ConnectionHandle connectionHandle, const std::vector<RegisterMemoryDesc> &memoryDescs,
                      std::vector<MemHandle> &memoryHandles);
```

## UnregisterMemory

```C++
Input:
  memoryDescs: N 个Unregister注册内存描述
    connectionHandle: 内存所属的连接句柄
    memoryHandle: 待解注册的内存句柄

Output:
  std::vector<Status>: 每个内存解注册结果
  statuses[i] 对应 memoryDescs[i]
  
  
struct UnregisterMemoryDesc {
  ConnectionHandle connectionHandle;
  MemHandle memoryHandle;
};

std::vector<Status> UnregisterMemory(const std::vector<UnregisterMemoryDesc> &memoryDescs);
```
